# Have You Tried Turning It Off?

Entry for the make.fun bounty
`u-motasimfuad-have-you-tried-turning-it-off-154a938b`.

`main.py` (stdlib only) writes one funny line, spoken by a hopeless tech
support agent to a desperate customer, to `/output/entry.txt`.

Run it:

```sh
python3 main.py
```

The entry is 130 characters, inside the 1-199 gate:

> Good news: your computer isn't broken, it has just stopped trying, and honestly, same. Have you tried turning it off and on again?
